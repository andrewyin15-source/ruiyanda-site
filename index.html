Product Line · 01

表观 · 翻译 · 转录调控

19 项核心服务，覆盖染色质调控与基因表达全链条。

表观组学

Epigenomics9 项
  1. m⁶A 甲基化测序检测 mRNA 上 m⁶A 修饰的分布。
    →
  2. DNA 甲基化测序测定 DNA 上的 5-甲基胞嘧啶分布。
    →
  3. ChIP-seq用特异性抗体沉淀目标蛋白或组蛋白修饰结合的 DNA 片段，经建库测序获得全基因组位点分布，是解析蛋白-DNA 互作与组蛋白修饰图谱的经典方法，可与对照样本比较识别差异结合位点。
    →
  4. ATAC-seq利用 Tn5 转座酶优先切割开放染色质并插入测序接头，通过测序读段的位置推断全基因组可及区域。
    →
  5. CUT&Tag在完整细胞核内用转座酶直接切割与目标蛋白结合的染色质并插入接头，无需甲醛交联，背景低、起始量需求小，可在低细胞数样本中定位组蛋白修饰与转录因子结合位点。
    →
  6. RIP-seq用抗体免疫沉淀特定 RNA 结合蛋白及其结合的 RNA 复合物，经交联与片段化后测序，获得该蛋白的靶标 RNA 谱；CLIP 类方法在此基础上通过交联位点把结合位置精确到单碱基。
    →
  7. Bulk TCR/BCR对样本中的 T 细胞与 B 细胞免疫受体重排区域进行扩增测序，通过 V(D)J 重组片段比对还原克隆型序列，实现免疫组库的定量刻画与克隆谱追踪。
    →
  8. FOODIE采用固定化转座酶在活细胞或组织中捕获与转录因子结合的开放 DNA 片段，保留细胞核内的真实微环境与共调控关系，定位精度高，可与表观修饰和表达数据联合构建调控网络。
    →
  9. Hi-C在细胞核内固定并裂解染色质后交联近邻片段，经限制性内切酶消化、末端修复与连接后建库测序，以配对末端信息重建全基因组三维接触频率，识别拓扑关联域等空间结构。
    →

翻译组学

Translatomics7 项
  1. 核糖体印迹分析用核糖体与 mRNA 交联后消化核糖体，收集核糖体保护片段建库测序。
    →
  2. 翻译碰撞检测在核糖体印迹基础上通过特定酶切策略富集核糖体碰撞形成的二聚体（disome）信号，碰撞强度反映翻译停滞与核糖体排队，从而区分停滞与无义介导降解等下游命运。
    →
  3. 多聚核糖体图谱分析用核糖体与 mRNA 的蔗糖梯度分离收集不同大小的多聚核糖体复合物后测序，按沉降系数归类比较，解析核糖体占位分布；RNC-seq 则通过交联富集核糖体结合的 RNA，获得更完整的翻译相关转录本视图。
    →
  4. 三代翻译组测序直接对翻译相关的 RNA 分子做长读长测序，跨越可变剪接位点与 poly(A) 尾，读长既可用于异构体层面的表达定量，也可结合核糖体关联信息解析异构体特异的翻译调控。
    →
  5. tRNA 测序专门针对 tRNA 与其衍生片段（tsRNA/tRF）建库测序，可同时获得转录本全长序列、序列修饰特征与末端丰度分布；Charged tRNA 分析进一步区分已负载氨基酸与未负载的 tRNA，反映翻译机器的实际可用池。
    →
  6. Poly(A) 尾测序在反转录过程中对 poly(A) 尾进行测序，测定每个转录本尾部长度与末端序列分布，并可结合长读长构建全长转录本视图，直接反映 mRNA 稳定性与翻译起始效率。
    →
  7. 翻译多组学联合分析以长读长或高灵敏质谱为核心，结合 Ribo-seq 与翻译组数据，在同一批样本上联合解析新翻译事件，把非经典 ORF、框架内 ORF 与小肽序列与抗原肽段进行交叉比对。
    →

转录调控组学

Transcriptomics3 项
  1. 转录组测序对样本中的 mRNA 进行建库测序，按比对到参考基因组的位置定量表达量，得到全基因表达谱，并通过差异分析筛选变化基因，再做功能富集把差异落到通路层面。
    →
  2. 全转录组测序在保留 mRNA 之外同时富集长链非编码 RNA、环状 RNA 与小 RNA 建库测序，一次覆盖多类非编码转录本，并通过链特异性建库区分正义与反义转录本。
    →
  3. 微量全转录组测序针对极低 RNA 量的样本优化建库流程，兼容 FFPE 降解 RNA、外泌体、血浆与细胞上清等微量材料，通过链特异性建库保留转录本方向信息并降低背景。
    →

本组怎么用

表观调控、翻译效率与转录本丰度三层证据可互相印证：先用转录组定位差异表达，再用表观组学追溯调控元件，最后用翻译组学验证是否真的影响到蛋白产出。

样本要求

总 RNA、总染色质与单细胞核悬液；细胞系与组织均可，低起始量与 FFPE 方案可评估。

交付内容

各组学标准数据集 + 联合分析图表（差异基因、开放性峰与翻译效率的对应关系）+ 解读报告。

18 项服务，从分子到代谢全景覆盖。

蛋白组学

Proteomics5 项
  1. TMT 标记定量蛋白质组学用串联质谱标签对不同样本的肽段进行化学标记，使多个样本在一次质谱运行中共测，通过报告离子比值实现跨样本的相对定量，是多组样本比较的主流方案。
    →
  2. LabelFree / 4D-LabelFree不做同位素标记，直接依据肽段的保留时间与质荷比进行鉴定，天然离子流强度与飞行时间信息共同支持定量，在高深度与大规模样本比较中表现稳定。
    →
  3. DIA / 4D-DIA / Astral-DIA采用全离子碎片化并行采集的采集策略，不依赖特定 MS/MS 事件触发，循环稳定、重现性好；引入离子淌度维度后进一步提升复杂度样本的区分能力。
    →
  4. 修饰蛋白质组学在蛋白酶解后用特异性抗体富集修饰肽段再做质谱鉴定，定位到具体残基位点，配套的糖基化分析则通过特异性标记与多级质谱策略解析位点与结构。
    →
  5. Olink 蛋白质组学采用邻近延伸技术，两条带标签的抗体同时结合目标蛋白后寡核苷酸延伸形成可量化的信号，检测灵敏度极高，特别适合体液中低丰度蛋白与细胞因子网络的定量。
    →

代谢组学

Metabolomics6 项
  1. 非靶代谢组不做预设靶标，对样本中可检测的小分子做全谱采集，通过保留时间与二级质谱谱库比对完成代谢物注释，可发现未知差异代谢物，是代谢标志物探索的起点。
    →
  2. 脂质代谢组针对脂质分子类别进行专门的全谱检测，覆盖多个脂质大类的分子种与结构异构体，输出以脂质亚类与分子种为单位的定量矩阵，刻画膜脂与信号脂质的整体变化。
    →
  3. 定量脂质组在非靶全谱的基础上锁定关键脂质分子做高选择性定量，常配合同位素内标进行绝对定量，重复性与灵敏度都优于非靶结果，适合机制验证阶段。
    →
  4. 高通量靶向代谢组预先设定目标代谢物清单并为其建立专属方法与定量标准，用高选择性离子对监测实现大批量样本的精确检测，兼顾通量与定量可靠性。
    →
  5. 中药代谢组把中药或复方给药前后的多成分代谢谱与体内代谢物谱对照分析，追踪原型成分与代谢产物的转化路径，并对关键成分做靶向确证。
    →
  6. 顶空 GCMS 代谢组学利用顶空进样让挥发性组分直接进入气相色谱，与质谱联用实现挥发性代谢物的分离与鉴定，兼具定量能力与保留指数辅助的库匹配。
    →

微生物组学

Microbiomics5 项
  1. 肿瘤内微生物测序针对肿瘤组织中含量极低的微生物信号做专项检测，通过严格对照与去污染策略区分真实微生物序列与背景噪声，并给出菌种组成与丰度，刻画肿瘤微环境中的微生物定植情况。
    →
  2. 宏基因组测序不对样本中的微生物做单菌分离，直接提取环境总 DNA 建库测序，同时获得群落的物种组成与功能基因信息，通过 binning 还能还原出部分未培养微生物的基因组草图。
    →
  3. 微生物群落多样性对细菌 16S 或真菌 ITS 区域的保守区段做高深度扩增测序，基于序列变异构建群落组成谱，计算 α/β 多样性并做差异菌群与标志物种分析，是菌群研究的标准入口方案。
    →
  4. 全长 16S rDNA 测序扩增并测序 16S rRNA 基因全长序列，保留多个可变区的信息，可结合现代分类数据库在物种水平甚至菌株水平做精确鉴定与系统发育分析。
    →
  5. 单菌基因组和原核转录组对纯化单菌做全基因组测序完成组装与注释，同时对该菌做转录组测序，两套数据联合起来把基因型与表达型对应起来，解释菌株的代谢能力与调控状态。
    →
